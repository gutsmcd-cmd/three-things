# Three Things

A dead-simple daily priorities app: pick at most three must-do tasks for today, check them off, and start fresh when the calendar day rolls over—no accounts, no sync, just local focus.

```bash
npm install && npm run dev
```

Production build:

```bash
npm run build
```

Then preview with `npm run preview`.

## Try it on your phone

After GitHub Pages deploys (Actions tab), open:

https://gutsmcd-cmd.github.io/three-things/

On iPhone: Safari → Share → Add to Home Screen.  
On Android: Chrome → Install app / Add to Home screen.
